# GPT-Image2-Skill (prompt craft for slide images)

Prompt-writing guides from [wuyoscar/gpt-image2-skill](https://github.com/wuyoscar/gpt-image2-skill)
(MIT licence, copied at commit `8a1e114` on 18 Nov 2026). Only the guides used for
Overture's slides are kept, as reference text; the skill's CLI and example images
are not included. Overture's slides are still generated with
`content-engine/scripts/generate_slides.py`.

- `craft.md`: the prompt checklist (canvas first, capture context, scene density,
  separate material/lighting/palette controls, bounded style anchors, targeted
  negation).
- `gallery-*.md`: example prompts per category (photography, fine-art painting,
  illustration, beauty & lifestyle, architecture & interior, watercolour).

How the engine uses it is in `../processing-runbook.md` → "Reimagine slides".
